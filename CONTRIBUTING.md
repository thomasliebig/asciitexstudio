# Contributing to AsciiTeX Studio

Contributions that make the editor easier to try, understand, or trust are especially valuable.

- Report browser and operating-system details with UI or persistence bugs.
- Include a minimal project ZIP or source fragment for compiler issues.
- Check both green and amber themes for visual changes.
- Keep document processing local-first; new network transmission must be explicit and documented.
- Run `npm ci` and `npm run build` before opening a pull request.

For larger UI, storage, or compiler changes, please open an issue first. Focused pull requests are easier to review and ship.
